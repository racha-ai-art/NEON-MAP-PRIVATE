# NEON MAP 0.10.0 — GM Workspace

แผนที่สำหรับ **GM ใน SillyTavern** ใช้ผัง 2D มองจากด้านบนที่วาดในเบราว์เซอร์ มีหมุดและตัวละครที่กดได้ แยกข้อมูลส่วนตัวของ GM ออกจากข้อมูลที่อนุญาตให้ส่งเข้า AI

รุ่นนี้ปรับจาก 0.9.17 ทั้งเส้นทางการใช้งาน ไม่ได้แก้เฉพาะปุ่มเปิดปิด

## เริ่มใช้

1. เปิดแชท แล้วแตะวงกลม MAP จะเห็นสถานที่จาก Character / Lorebook และผังตั้งต้นที่ระบุว่าเป็นข้อมูลสมมติ
2. แตะสถานที่ → **เข้าไปดู** → **+ ชั้น** → เลือกชั้น → **+ ห้อง** → เข้าไปดูห้อง
3. เปิดแท็บ **ตัวละคร** แล้วใช้ **ตั้งไว้ที่มุมมองนี้** หรือเลือกสถานที่แล้วใช้ **ตั้งตำแหน่งที่นี่**

USER มีวงแสงสีเขียวกะพริบเบา ๆ ปุ่ม **หา USER** เปิดระดับที่มีข้อมูลตำแหน่งของผู้เล่น กด X มุมขวาบนเพื่อพับกลับเป็นวงกลม

อ่าน [คู่มือ GM](GM_GUIDE_TH.md), [เหตุผลและสถาปัตยกรรม](ARCHITECTURE_TH.md) และ [ผลทดสอบ](TEST_REPORT_TH.md)

## ใช้ฟรีและโทเคน

| สิ่งที่ทำ | เรียกโมเดลเพิ่ม | ข้อความเพิ่มใน prompt |
| --- | --- | --- |
| เปิดแมป เลื่อน ซูม อ่านข้อมูลที่มีอยู่ | ไม่เรียก | ไม่มี |
| สร้างชั้น/ห้อง วางหมุด ย้ายตัวละคร บันทึก GM | ไม่เรียก | ไม่มี |
| อ่านข้อความแชทและ Lorebook ใน SillyTavern | ไม่เรียก | ไม่มี |
| เปิดการรับรู้ในห้องและเลือกตัวละคร | ไม่เรียกโมเดลแยก | เฉพาะข้อความห้องที่ GM ใส่ สูงสุดรวม 1,100 อักขระ |
| กดสร้างภาพจาก API ภายนอก | เรียกเมื่อกดและยืนยัน | เป็นคำขอภาพแยก ไม่เพิ่มให้โมเดลโรลเพลย์ |

ค่าเริ่มต้น **GM เท่านั้น / 0 โทเคนเพิ่ม / ปิด API ภายนอก** การใช้โมเดลแชทเดิมของ SillyTavern ยังเป็นไปตามบริการที่ผู้ใช้ตั้งไว้

## คุณสมบัติ

- ระดับโลก → สถานที่ → เลือกชั้น/ผังชั้น → ห้อง
- ปุ่มสถานที่ชื่ออ่านง่าย ขนาดตัวหนังสือไม่ย่อตามซูมภาพ
- หมุดบันทึก อันตราย ภารกิจ ความลับ หมุดโปรด และเป้าหมาย
- ตัวละครแยกจากเลเยอร์ภาพ มีตัวช่วยหา USER และย้ายหมุดในห้องตามทางเดินของผัง GM
- รับตำแหน่งใหม่จากข้อความที่ระบุชัด หากข้อมูลกำกวม GM ตั้งเองได้ โดยไม่ต้องบังคับ AI ให้เขียนแท็กเพิ่ม
- การรับรู้แยกตามห้องและตัวละคร ปิดเป็นค่าเริ่มต้น ไม่รวมบันทึกส่วนตัว GM
- ข้อมูลแผนที่แยกแชท ใช้ Chat Metadata ของ SillyTavern และสำเนากู้คืนล่าสุดในแท็บเพื่อรับมือการรีโหลดระหว่างบันทึก
- API ภาพอยู่ในเครื่องมือขั้นสูง ต้องกดและยืนยัน ไม่มีการสร้างภาพภายนอกอัตโนมัติ
- มุมมองภาพภายนอกกำหนดเป็น orthographic top-down; รูปเป็นพื้นหลัง หมุดและผังโต้ตอบยังทำงานแยกกัน

ผังเริ่มต้น รูปร่างห้อง และเฟอร์นิเจอร์เป็น **ผังประมาณการของ GM** ไม่ใช่ข้อเท็จจริงที่โมเดลยืนยัน การอ่านภาษาธรรมชาติในเครื่องไม่รับรองว่าจะเข้าใจทุกสำนวน

## ติดตั้ง

วาง URL repository ใน **Extensions → Install Extension** หรือกด Update สำหรับตัวที่ติดตั้งไว้แล้ว จากนั้นรีโหลดหน้า ให้หัวแมปแสดง **GM · 0.10.0**

ไม่ต้องรัน npm install เพื่อใช้ส่วนขยาย ดู [INSTALL_PRIVATE_TH.md](INSTALL_PRIVATE_TH.md) สำหรับการวางไฟล์เอง

## การทดสอบ

ผ่าน Node 27 กรณี, browser fixture 23 กรณี และการใช้งานกับ **SillyTavern 1.19.0 จริงในเครื่องทดสอบ 14 กรณี** รวมการตรวจข้อมูลที่เขียนลงไฟล์แชทบนเซิร์ฟเวอร์และการรีโหลด

การทดสอบมือถือเป็น Chromium พร้อม viewport/touch emulation ไม่ใช่โทรศัพท์ของผู้ใช้ และไม่ได้ส่งงานเสียเงินจริงไปบริการภาพ

สำหรับพัฒนา: npm test, npm run test:browser และ npm run test:live (ตั้ง SILLYTAVERN_PATH ไปยัง checkout สำหรับทดสอบที่แยกจากข้อมูลจริง)
